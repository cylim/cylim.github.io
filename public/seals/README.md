# public/seals

The cinnabar seals (design.md §4.4). Generated by `scripts/make-seals.mjs`; do not edit by hand. Colours come from `tokens.color.cinnabar` and `cinnabarDeep`. Carving roughness, the darker pressed rim and uneven 印泥 are baked in as geometry and masks. There are no SVG filters, so they are cheap on phones.

`seals.json` lists the angles and files for code.

## Sizing and the baked angle

Files with a baked angle have a padded viewBox (`-2.5 -2.5 105 105`) so the rotated corners never clip. The seal fills 100/105 of the box, so size the element at `sealSize × 1.05` (29.4 px for the nav) to keep the design size. Base files use `0 0 100 100`.

The stamp animation (§4.4: scale 1.06 → 1, rotation +1.5° → rest, 220 ms, then the 400 ms bleed ring) should animate `rotate: 1.5deg → 0deg` on a baked file, because the resting angle is already in the drawing. Seals never animate after they land.

## Embedding

- Easiest is `<img src="/seals/lin-zhuwen-nav.svg" alt="" width="29" height="29">`: cached, no id clashes, and the browser rasterises it once.
- To inline, paste the file as is. Each file uses its own id prefix (`lzn-`, `lbh-`, `lzf-`, `lz-`, `lb-`), so different seals can share a page. Do not inline the same file twice on one page.
- Each file is 17 to 22 KB raw and 3.5 to 4.6 KB gzip, because of the carved outlines. Keep them out of the prerendered HTML budget by using `<img>` for the nav mark.
- Favicon: `/favicon.svg` (白文 with paper strokes, legible at 16 px on light and dark tabs), `/favicon.ico` (16 and 32 px), `/apple-touch-icon.png` (180 px on paper).

## Where the letterforms come from

The 林 is traced by hand as stroke centrelines on the 100 × 100 grid, after the Shuowen small-seal drawings of 林 and 木 on Wikimedia Commons (public domain; see `/CREDITS.txt`). It is squared up to fill the field, as seal carvers adapt 小篆.

Regenerate with `node scripts/make-seals.mjs` (add `--png` for previews in `/tmp/cy-seals`). It needs `rsvg-convert` and ImageMagick for the raster icons.
