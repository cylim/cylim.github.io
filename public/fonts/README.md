# public/fonts

## What each subset holds

- **Cormorant Garamond 600**: ASCII, Latin-1 letters, `‘ ’ “ ” – — … · × ©`. Kerning and standard ligatures. It is a display face, never below 24 px, so it has no pinyin.
- **Source Serif 4 400 and 600**: ASCII, Latin-1 letters and common signs, every pinyin tone vowel in both cases (ā á ǎ à … ǖ ǘ ǚ ǜ ü, plus ń ň ǹ), typographic punctuation and arrows, and any other non-ASCII character found in the sources. Kerning, ligatures, tabular figures (`font-variant-numeric: tabular-nums`). The 600 face also keeps small caps (`smcp`, `c2sc`) for the `label` style's `font-variant-caps: all-small-caps`.
- **JetBrains Mono 400**: the same Latin set plus box drawing (`─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼ ╭ ╮ ╯ ╰`), blocks (`█ ▌ ▐ ░ ▒ ▓`) and `▸ ▶ ◀ ▲ ▼ ✓ ✕`. Code ligatures (`calt`) are stripped, so `->` stays two characters.
- **LXGW WenKai**: every CJK character in `src/content`, `src/lib/qimen`, `src/lib/calendar`, `src/dom`, `src/sections`, `src/core/text` and `index.html` (comments, tests, Node-side `.mts` tools and regex range bounds such as `[㐀-鿿]` excluded), plus the full chart vocabulary in `scripts/collect-cjk.mjs` `CHART_GLYPHS` (stems, branches, palaces, stars, doors, both deity traditions, 24 terms, dun/ju/yuan words, numerals, directions), CJK punctuation, and `0-9 : . - / ( ) ·` so troika can draw mixed labels like `离9` or `阳遁4局` in one font. `vert` is kept for vertical text. The exact list is `wenkai-subset.glyphs.txt`.
- **Ma Shan Zheng**: only `入 林 木 屋 九 宫 石 灯` (`mashanzheng-subset.glyphs.txt`). `check-glyphs` fails if a hero, nav or inscription accent in `src/content` needs anything else.

## Using them

CSS (the DOM layer owns the stylesheet; `font-display: swap`, and preload only what the first screen needs):

```css
@font-face { font-family: 'Source Serif 4'; font-weight: 400; font-display: swap; src: url(/fonts/source-serif-4-400.woff2) format('woff2'); }
@font-face { font-family: 'Source Serif 4'; font-weight: 600; font-display: swap; src: url(/fonts/source-serif-4-600.woff2) format('woff2'); }
@font-face { font-family: 'Cormorant Garamond'; font-weight: 600; font-display: swap; src: url(/fonts/cormorant-garamond-600.woff2) format('woff2'); }
@font-face { font-family: 'JetBrains Mono'; font-weight: 400; font-display: swap; src: url(/fonts/jetbrains-mono-400.woff2) format('woff2'); }
@font-face { font-family: 'LXGW WenKai'; font-weight: 400; font-display: swap; src: url(/fonts/wenkai-subset.woff2) format('woff2'); }
@font-face { font-family: 'Ma Shan Zheng'; font-weight: 400; font-display: swap; src: url(/fonts/mashanzheng-subset.woff2) format('woff2'); }
```

```html
<link rel="preload" href="/fonts/source-serif-4-400.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="/fonts/cormorant-garamond-600.woff2" as="font" type="font/woff2" crossorigin>
```

troika (3D) reads `.woff`, never `.woff2`: `font={fontFiles.cjk.woff}` for CJK glyphs, `fontFiles.display600.woff` for scroll titles, `fontFiles.body400.woff` for the English labels.

## The hero 入林 without a font

`/glyphs/hero-rulin.svg` is 入林 outlined from Ma Shan Zheng, stacked vertically in a `1000 × 2000` viewBox (one em per character), `fill="currentColor"`, `aria-hidden="true"`. Inline it (or its path data) in the prerendered hero so first paint needs no CJK font, set its width to `1em` of `--fs-hero-cjk`, and keep the accessible text (and `lang="zh-Hans"` gloss) in the DOM next to it. `/glyphs/mashanzheng.json` has the path of every display glyph in a 1000-unit em box, y down, for any other inline use.

## Regenerating

```sh
node scripts/fetch-fonts.mjs     # once: downloads the OFL sources into .fonts-src/ (git-ignored)
npm run gen:fonts                 # subset-fonts.mjs, rewrites this folder and /glyphs/
npm run check:glyphs              # CI runs this; fails on any character the subsets lack
```

Rerun `gen:fonts` whenever copy adds a character, then commit `public/fonts/` and `public/glyphs/`.
